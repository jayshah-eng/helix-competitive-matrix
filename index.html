Key Competitive Insights

GenoSphere™ Competitive Advantages

  • Only platform combining Exome+ WES with linked EHR + claims + recontact at 400K+ scale
  • World's largest specialized GLP-1 clinicogenomic cohort (55K+)
  • OMOP-harmonized — interoperable with existing pharma data infrastructure
  • 100% consented recontact enables clinical trial recruitment, not just observational research
  • Purpose-built cohorts (cardiometabolic, GLP-1, autoimmune, MASH) vs. general population
  • Commercial partnership model with rapid feasibility turnaround via Explorer™

Where Competitors Lead

  • UK Biobank: Gold-standard WGS reference (500K); deep phenotyping; academia preferred
  • All of Us: Most diverse US cohort; wearable data; free researcher access
  • TriNetX: Largest EHR scale (250M+); site network for trial recruitment feasibility
  • Tempus / Flatiron: Dominant in oncology multimodal + RWE regulatory submissions
  • deCODE Genetics: Most complete population-level WGS dataset (60% Iceland)
  • Epic Cosmos: Deepest structured EHR network; near-real-time data; FHIR native

Universal Gaps in the Market

  • No platform offers WGS + linked EHR/claims + recontact in a single commercial offering
  • Public biobanks (UK BB, All of Us) restrict commercial recontact and licensing
  • Oncology platforms (Tempus, Flatiron) have no rare/cardiometabolic depth
  • EHR networks (TriNetX, Epic Cosmos) lack raw genomic data entirely
  • Population biobanks are largely single-ancestry or single-country
  • Rare variant discovery requires WES/WGS — array-only platforms miss ~95% of variants

Pharma Use Case Fit

  • Target discovery: deCODE, UK Biobank, FinnGen (rare variant → gene)
  • Trial enrichment / patient ID: GenoSphere, DiscovEHR, All of Us (recontact)
  • Feasibility / site selection: TriNetX, Epic Cosmos (scale + site network)
  • Oncology RWE / regulatory: Flatiron, Tempus (FDA-recognized)
  • Precision effectiveness (cardiometabolic): GenoSphere uniquely positioned
  • GLP-1 / obesity outcomes: GenoSphere (only purpose-built genomic cohort)

Key Competitive Insights

Helix Explorer™ — Where It Leads

  • Only no-code tool natively combining genomic variant + PRS queries with EHR/claims phenotyping
  • Recontact + trial matching in a single workflow — feasibility through to recruitment
  • OMOP-native output integrates directly with pharma data warehouses
  • Purpose-built therapeutic cohorts reduce study setup time vs. general biobanks
  • Instant N-count feasibility without IRB for scoping studies

Biggest Analytical Depth Gaps

  • Notebook integration — Explorer™ lacks R/Python access (unlike UKB-RAP, Terra, All of Us)
  • Survival analysis — most GUI tools lack built-in KM; researchers export to R/SAS
  • Propensity matching — only TriNetX, Aetion, IQVIA have built-in PSM
  • Temporal logic — ATLAS leads with washout periods, gap logic, and index date sequences
  • Multi-cohort overlap / UpSet plots — missing from nearly all platforms

Interface Design Trends

  • Shift toward hybrid (GUI + notebooks) — pure code-first platforms losing researchers
  • ATLAS dominates open-source but has steep learning curve; TriNetX winning pharma with GUI
  • All of Us Workbench pioneered GUI + cloud notebooks toggle — others following
  • Palantir Foundry most powerful but highest implementation overhead
  • Epic Cosmos fastest for EHR feasibility but no genomics and no export

Strategic Gaps Explorer™ Could Close

  • Add notebook/API layer (R, Python) for power users without rebuilding the GUI
  • Built-in KM / survival analysis would eliminate the most common "export to R" step
  • Propensity score matching UI would make Explorer™ sufficient for full RWE study design
  • Federated multi-site query capability would expand beyond the current GenoSphere population
  • Shareable cohort definitions / workspace collaboration for multi-investigator studies
